# Privacy-Wiper
A tool that overrides a file/folder before deleting it so the data inside the files cannot be traced by anyone

#How does it work?:                                                                                                                          
It overrides the data of a file and makes it empty before deleting it so if somebody or someone traced it they cannot access the data of the file because it was overridden empty
